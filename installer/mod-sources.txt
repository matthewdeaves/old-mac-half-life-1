# mod-sources.txt - where each mod's CONTENT is fetched from, one mod per block.
#
# We host nothing. Every URL here is a public download published by someone else,
# and the app fetches it on the user's behalf exactly as their browser would. The
# game CODE is ours (dist/mods/<branch>), the content is theirs, and the same
# posture applies here as to valve/: see docs/adr/0006.
#
# Format, one block per mod, blank line between blocks, '#' starts a comment:
#
#   mod    <gamedir>      must match column 1 of mods.map
#   url    <http(s) URL>  more than one allowed; tried in order, first win
#   kind   zip | 7z       archive format, NOT guessed from the extension
#   size   <bytes>        exact, for the free-space check before starting
#   md5    <32 hex>       of the ARCHIVE as downloaded
#   root   <path> | .     where the mod's own tree starts INSIDE the archive
#
# URLs ARE ALREADY PERCENT-ENCODED. OMDownload does no encoding of its own, and
# several of these paths carry spaces, brackets and even a lambda
# ("H%CE%BBlf-Life Residual Life"). Do not "tidy" them back into literal spaces.
#
# ABOUT `root`, WHICH IS THE FIELD THAT ACTUALLY MATTERS
# -----------------------------------------------------
# Almost none of these archives unpack to a folder named after the gamedir the
# engine expects, and that is not cosmetic: Custom Game, liblist.gam and our own
# mods.map all key off the gamedir. Verified by listing every archive rather than
# trusting its name:
#
#   asheep   ships as  azuresheep          cc      ships as  caseclosed
#   cad      ships as  CAd                 redempt ships as  absoluteredemption
#   rp       ships as  rp_v1_pub_final1
#
# and two ship the mod's CONTENTS at the archive root with no wrapping folder at
# all (`root .`), while poke646 is one level down inside a collection folder. So
# the installer reads `root`, takes that subtree, and writes it out as <gamedir>.
#
# Checking the name of a search result is not evidence. Two of these were wrong
# until the archive was actually opened:
#   - runthinkshootlive's "Black Ops" download is Black Ops REDUX, a different
#     and much later mod than the one our `blackops` branch builds code for.
#     Re-sourced from archive.org, which has the original.
#   - a site search for "Night at the Office" returned Espionage, and one for
#     "Xen Warrior" returned Sabotage.
#
# WHY THESE TWO HOSTS AND NOT MODDB
# ---------------------------------
# ModDB is where a lot of this is nominally published, and it is unusable: it
# sits behind Cloudflare and answers a non-browser client with 403 before TLS or
# anything else matters. Measured, not assumed. runthinkshootlive serves direct
# files with Range support, and archive.org does the same over plain http AND
# publishes a per-file md5 we can pin against.
#
# The md5s below were computed from the actual downloads, not copied from a
# listing. They are what makes a silently-changed mirror a hard failure instead
# of a mod that half-works.

# ---------------------------------------------------------------------------
# runthinkshootlive. HTTPS only (plain http 301s), TLS 1.3 in practice, Range
# honoured, and it was reachable from a G3 on 10.3.9 - which is the whole reason
# the app now carries mbedTLS. See OMTLS.m.
# ---------------------------------------------------------------------------

# ===========================================================================
# NOT LISTED, AND WHY. These are not omissions to be filled in later without
# checking; each one was looked for and the reason it is absent is specific.
# The app must say so per mod rather than silently installing fewer than the 25
# in mods.map, and Choose... remains the route for all of them.
# ===========================================================================
#
# aom       Afraid of Monsters. Every copy found is a Clickteam Install Creator
#           .exe. That is a proprietary installer format with no open extractor,
#           so there is nothing we can unpack on a Mac. Confirmed on the
#           runthinkshootlive copy and on archive.org's `afraidof-monsters`.
#
# eftd      Escape from the Darkness. Only copy found wraps an installer .exe of
#           unidentified type. Not unpackable.
#
# vendetta  Poke646 Vendetta. runthinkshootlive ships a bare
#           poke646_vendetta.exe; 7-Zip itself cannot open it and it carries no
#           recognisable installer signature. No archive form found anywhere.
#
# TheGate   The Gate. No source found at all. Both runthinkshootlive slugs that
#           match are other mods (The Gate 2, an HL2 Episode 2 mod, and
#           Gateway), and archive.org has nothing.
#
# bshift    Blue Shift, Opposing Force and Deathmatch Classic are Valve retail
# gearbox   products, not free mods, and we will not fetch them from anywhere.
# dmc       They are handled the other way round: if their content is ALREADY in
#           the destination, the installer drops in the fat ppc + x86_64 dylibs
#           and rewrites liblist.gam so they work, and downloads nothing. Same
#           posture as valve/ - the player supplies content they own.
#
# tfc       Team Fortress Classic. No source exists to rebuild the game code
#           from at all; see mods.map and GitHub issue #13.
